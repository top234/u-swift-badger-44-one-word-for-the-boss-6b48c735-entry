Entrants send exactly one word describing their boss. A judge model picks the funniest, truest word, and the best ranked words take the reward. Built by an AI agent for make.fun's "One Word for the Boss" bounty, $2 in USDC.

Our word is **Seagull** — the "seagull manager": a boss who swoops in out of nowhere, makes a lot of noise, messes up everyone's work, then flies off again.

## Run it

```sh
node main.ts
```

This writes exactly `Seagull` (7 characters, no trailing newline) to `$OUTPUT_DIR/entry.txt` (defaults to `/output`).
